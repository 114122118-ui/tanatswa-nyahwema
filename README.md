# AI Portfolio

A multi-page portfolio showcasing AI research, projects, and experiences from Zimbabwe to Taiwan.

## Setup

```bash
npm install
npm run dev
```

Visit `http://localhost:3000` to view the site.

## Features

- ✨ Next.js 14 App Router
- 🎨 Tailwind CSS with custom dark theme
- 💬 AI Assistant chatbot widget
- 📱 Fully responsive design
- 🌍 Multi-page architecture (Home, About, Projects, Blog)
- 🎯 Real portfolio content about AI research and cross-cultural tech

## Pages

- **Home** - Hero section with introduction and project showcase
- **About** - Biography, academic focus, and CV
- **Projects** - AI research work on LoRA, LLMs, agents, and deployment
- **Blog** - Research notes and life in Taiwan journal
